# GPT酱桌宠 🐉

一只会待在 Windows 桌面上的 Q 版二次元桌宠。你可以摸摸她、戳戳她、把她拎起来晃一晃，也要记得给她喂食、喂水、洗澡和治病。

她有自己的心情、健康和生活节奏：会因为饿了、口渴或太久没人理而闹脾气，也会在互动时回应你。她还会攒金币、逛商店、使用道具，偶尔嘴硬地吐槽几句。

> 本项目使用 Electron 构建，包含桌宠互动、养成系统、透明窗口、托盘菜单和可选的动态渲染效果。

## 功能概览

### 桌面互动

- 透明背景桌宠窗口，可在桌面上自由拖动。
- 点击头部可以摸头；点击身体可以戳她。
- 连续点击可能让她生气。
- 按住并拖动可以拎起她；松开后会落下并弹跳。
- 鼠标悬停时可以查看状态提示。
- 右键桌宠或托盘图标可以打开操作菜单。
- 双击桌宠可以打开状态、商店和背包面板。
- 可以从托盘显示或隐藏桌宠。

### 养成与道具

- 管理饱食、水分、心情、清洁和健康等状态。
- 使用食物、饮料、药品、清洁用品和玩具。
- 购买并使用商店道具。
- 每日签到并获取金币。
- 状态过低时可能出现生病等状况；健康降到 0 后会倒下，可使用复活药恢复。
- 桌宠会根据状态、互动和时间变化切换表情、立绘与台词。

### 个性与动画

GPT酱是嘴硬、傲娇、爱吐槽的大小姐。她会根据互动和状态作出不同反应，例如开心、害羞、生气、饥饿、口渴、虚弱、睡着或转晕。

项目包含两套动态渲染实现：

- **默认渲染器：`src/live.js`**  
  对整张立绘进行权重变形，提供呼吸、摆动、视线与身体跟随等效果。
- **可选分部件渲染器：`src/parts-live.js`**  
  将头部、头发、身体和尾巴等部分组合渲染，支持更独立的部件动画。它不是官方 Live2D/Cubism 模型。

如果 WebGL 不可用，桌宠会回退到普通立绘显示。

## 运行环境

- Windows
- Node.js（建议使用 LTS 版本）
- npm

桌宠使用 Electron。首次安装依赖和下载 Electron 运行文件时需要网络连接。

## 快速开始

### 方式一：使用启动脚本

1. 安装 Node.js。
2. 下载或克隆本项目。
3. 运行 `启动桌宠.bat`。
4. 首次启动时，脚本会安装项目依赖；完成后会启动桌宠。

### 方式二：使用命令行

在项目目录打开终端并运行：

```bash
npm install
npm start
