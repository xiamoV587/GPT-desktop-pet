# GPT酱桌宠 🐉

Q 版二次元桌面宠物：站在桌面上，可以摸头、戳、拎起来晃，需要喂食、喂水、洗澡，生病了要吃药，还有金币商店。

## 运行（Windows）

1. 安装 **Node.js**（LTS 版）：https://nodejs.org/
2. 双击 **`启动桌宠.bat`**
   - 第一次会自动下载依赖（Electron 约 100MB，已配置国内镜像），需要几分钟
   - 之后每次双击就能直接启动
3. 想要独立的 exe：双击 **`打包成exe.bat`**，完成后在 `release` 文件夹里：
   - `GPT酱桌宠 1.0.0.exe`：免安装单文件版
   - `GPT酱桌宠 Setup 1.0.0.exe`：安装版

也可以用命令行：`npm install` 然后 `npm start`。

## 动态效果（v6：真正独立的部件图层）

当前入口改用 `src/parts-live.js`，不再加载旧版 `assets/layers` 尾巴。
新素材全部从 `assets/sprites` 的 444×420 完整原图重新拆取，原图没有覆盖。

| 主层 | 内容与动作 |
|---|---|
| 头部 | 脸、前发上部、耳朵、角；独立小幅转头、上下跟随、表情替换 |
| 后发 | 后发与下垂发束；根部跟随头部，下段延迟回摆 |
| 身体 | 衣服、手脚，翅膀作为子层；整体呼吸 |
| 尾巴 | 按原图轮廓重抠，含内侧尖刺；根部固定、向尾尖渐进弯曲 |

- **11 个可组合表情**：待机、眨眼、开心、生气、害羞、得意、委屈、饥饿、口渴、虚弱、转晕。
- **游戏内 9 个站姿状态接入分层**：idle、blink、happy、angry、shy、smug、hungry、weak、dizzy。
- 口渴端杯、饥饿端盘、吃喝、抱尾巴、睡觉、拎起、侧身等特殊姿态继续使用完整原图，保留道具与姿态；不声称所有姿态均已拆层。
- 切表情时共享身体、尾巴；部分表情还会自动眨眼。得意表情只提取眼神并沿用待机微笑，避免把原图遮嘴的手裁进脸上。
- 头部最大约 2 度转动、发梢约 3.4 像素、尾巴约 5.7 度；不使用会扯裂五官的大幅整图区域位移。
- 遮挡区域使用原图像素程序补全，不是原始 PSD，也不是官方 Live2D/Cubism 模型。大幅运动仍需要更精细的补绘。
- 点击判定采样当前渲染透明度，考虑外层旋转/缩放；WebGL 不可用或上下文丢失时回退到原始图片。

**查看效果**：用浏览器打开 `layers-preview.html`，可切换表情、单独开关图层、暂停、归零、对照原图及检查深色背景。完整互动仍在 `preview.html`。

生成器：`python art/tools/build_parts.py`。运行桌宠不需要 Python；仅重新生成素材需要稳定版 Python 3.10+ 及 `art/tools/requirements-parts.txt` 中的依赖。
旧版 `src/live.js`、`assets/layers/` 保留但不再由桌宠入口加载，可用于比较或回退。

## 性格与表情（v3）

GPT酱是 OpenAI 家的大小姐：嘴硬、傲娇、有点屑，最喜欢嘲讽隔壁的**蓝色大肥鱼**（DeepSeek 娘）。

| 情况 | 表情 / 表现 |
|---|---|
| 待机 | 随机露出**鄙视脸**（手托下巴坏笑），或拎着一只晕乎乎的小鲸鱼玩偶偷笑，配上嘲讽台词；偶尔还有两句连发的小剧场 |
| 睡觉 / 8 分钟没人理 | 自动**蜷成一团**，被自己的大尾巴圈住、翅膀当被子盖；偶尔说梦话 |
| 饱食 < 25 | 端着空盘子流口水，偶尔捂肚子 |
| 水分 < 25 | 吐舌头、流汗，举着倒空的杯子 |
| 心情 < 25 | 头顶小乌云下雨，抱着尾巴生闷气 |
| 健康 < 30 | 脸色发青、蚊香眼、贴创可贴，灵魂从嘴里飘出来 |
| 清洁 < 40 | 身上逐渐出现**灰斑和泥点**（越脏越明显，跟着身体一起动）；< 25 时还会冒出"臭味"波浪线 |

| 被拎着来回甩 / 鼠标绕着她的脸转圈 | **转晕**：蚊香眼，头顶星星转圈 |
| 从高处（约 300 像素以上）摔下来 | **摔疼**：抱头泪目，头上起包 |
| 鼠标离开 90 秒以上后又回到她附近 | **惊讶**："哦？回来了？……才、才没有在等你" |
| 快要自己睡着前 1 分钟 / 深夜 23 点到 5 点 | **打哈欠** |
| 摸头（30% 概率） | **傲娇**：害羞脸 + 嘴硬台词"哼、才没有很舒服！" |
| 签到、在商店买东西 | **得意叉腰** |

**待机屑**：待机时偶尔会捂嘴偷笑屑你一下，说和大肥鱼无关的屑台词（"盯着本小姐看这么久，是不是被迷住了？"）；嘲讽大肥鱼则用拎着鲸鱼玩偶的立绘。

**自动说话**：摸头、戳、悬停、喂东西等互动期间，以及互动结束后 20 秒内，她不会自己插话或做闲置小动作；每次互动都会重新计时。

**看鼠标**：身体会整体往鼠标那边稍微倾斜（不再单独转头，避免五官变形）。

状态**刚出现**和**恢复**时都会说话（比如"咕~……肚子饿了！投喂！立刻！马上！" / "吃饱了~ 活过来了！算你识相"）。
摸头、戳、拎起、落地、吃东西、洗澡等台词也都换成了大小姐口吻；脏的时候摸头、心情差时摸头都有专门的台词。
所有台词在 `src/game.js` 的 `LINES` 里，可以随意修改。

## 养成规则

| 数值 | 每小时下降 | 过低时 |
|---|---|---|
| 🍙 饱食 | 6 | < 25 饿肚子（捂肚子的立绘），< 20 开始掉健康 |
| 💧 水分 | 8 | < 25 口渴，< 20 开始掉健康 |
| 💗 心情 | 4 | < 25 生气、不开心 |
| 🛁 清洁 | 3 | < 20 掉健康，< 25 有概率生病 |
| ❤️ 健康 | — | < 50 后越低越容易**生病**；吃饱喝足时会慢慢恢复 |

- **生病**：发烧立绘，心情和健康持续下降，需要**感冒药**或**万能药水**。
- **死亡**：健康降到 0 会倒下（X_X 眼 + 光环 + 小幽灵的立绘）。倒下期间所有属性冻结，不会生病，也不会自己说话，戳她、提起来都没反应，吃喝、睡觉都用不了。
- **复活药** 💖（商店 50 金币）：只能在倒下时使用，没倒下时用会被她骂回来。复活后各项属性都很低（饱食/水分/心情 15，清洁/健康 20），要马上喂饭喂水，不然还会再倒下。
- **防死档**：倒下期间在线金币照样增加，而且是 **3 倍速**（约 50 分钟攒够一瓶），每日签到也能照常领。
- **睡觉**：心情恢复，健康恢复更快，饥饿和口渴下降减半。8 分钟没人理她会自己蜷起来睡着。
- **离线**：关掉程序后，最多按 12 小时结算，速度减半，不会一晚上就饿坏。
- **使用物品**：吃喝用药时物品图标只会在头顶冒一下，不会再塞到她手里。
- **金币**：在线每 3 分钟 +1，摸头 +2（每天上限 60），每日签到 +50。

存档位置：`%APPDATA%\deskpet-gpt\save.json`（设置在同目录的 `settings.json`）

## 文件结构

```
main.js          主进程：透明置顶窗口、拖拽/掉落物理、右键菜单、托盘、存档
preload.js       安全暴露给页面的接口
src/game.js      游戏逻辑：数值、物品、商店、生病、金币（改数值、加物品都在这里）
src/pet.*        桌宠窗口：立绘切换、程序动画、点击判定、气泡、特效
src/parts-live.js 新版独立图层渲染器：网格变形 + 弹簧物理
assets/parts/    新版头部/后发/身体/尾巴及表情贴图
layers-preview.html 分层动作检查页
src/live.js      旧版渲染器（保留，不再加载）
src/panel.*      状态 / 商店 / 背包面板
src/masks.js     立绘的点击判定遮罩（透明部分可以点穿到桌面）
assets/sprites/  立绘（透明 PNG，444×420）
assets/rig/      dirt.png 脏污贴图（其余为旧版资源）
assets/layers/   旧版身体/尾巴图层（保留，不再加载）
art/tools/       生成遮罩和部件贴图的 Python 脚本
preview.html     网页预览版（不装 Electron 也能在浏览器里试玩）
```

## 自定义

- **加商品**：在 `src/game.js` 的 `ITEMS` 里照格式加一行即可，商店和菜单会自动出现。
- **改台词**：`src/game.js` 里的 `LINES`。
- **换立绘**：替换 `assets/sprites/` 里同名 PNG（尺寸保持 444×420，角色脚底贴近图片底边），然后运行 `python art/tools/build_masks.py` 重新生成点击遮罩；
  若需要新版分层动画，还要修改 `art/tools/build_parts.py` 中的轮廓与表情区域，重新生成 `assets/parts/`，并核对支点及遮挡。
- **调动画幅度**：`src/parts-live.js` 中的头部、发梢、尾巴限幅与各 `Spring(k, c)`；检查页支持在安全上限内调整幅度。
